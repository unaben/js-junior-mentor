Task: Interactive Team Roster & Availability Toggle
Description
In this exercise, you will dynamically render a list of team members from an array of nested objects. Each list item will display the team member's avatar image, name, department, and an interactive status button that toggles between "Active" and "Inactive" when clicked.

Step-by-Step Instructions
	1	Target the Unordered List Container:
	◦	Select the <ul> element using document.querySelector('#team-roster').


	2	Write a Function renderRoster(members):
	◦	Clear the container content (container.innerHTML = '').
	◦	Write a for loop to iterate through members.


	3	Build the DOM Elements inside the Loop:
	◦	Create an <li> element using document.createElement('li') and set li.className = 'roster-card'.
	◦	Create the Image Element (<img>):
	▪	Use document.createElement('img').
	▪	Set its .src property using nested access: member.profile.avatarUrl.
	▪	Set its .alt property to the member's full name.
	▪	Add class avatar to the image element (img.className = 'avatar').
	◦	Create the Info Container (<div>):
	▪	Create a div element and give it class info.
	▪	Populate its innerHTML with an <h3> showing member.profile.fullName and a <p> showing 
		${member.profile.details.role} • ${member.profile.details.department}.
	◦	Create the Toggle Button (<button>):
	▪	Create a <button> element using document.createElement('button').
	▪	Set initial text content and class depending on member.isAvailable:
	▪	If true: Text = "Active", className = "toggle-btn btn-active".
	▪	If false: Text = "Inactive", className = "toggle-btn btn-inactive".


	4	Attach the Click eventListener:
	◦	Add a click event listener to the created button (button.addEventListener('click', ...)).
	◦	Inside the event listener, toggle the member's state:
	▪	Toggle member.isAvailable = !member.isAvailable (boolean negation!).
	▪	Update the button's text content ("Active" vs "Inactive").
	▪	Update the button's CSS classes (btn-active vs btn-inactive).


	5	Assemble and Append:
	◦	Append img, infoDiv, and button to the li card element (li.appendChild(...)).
	◦	Append the li card element to the main <ul> container.


	6	Execute:
	◦	Call renderRoster(teamMembers) at the bottom of your script.


Key Concepts Practiced
	•	DOM Element Creation: Using document.createElement('img'), li, div, button.
	•	Nested Property Reading: Accessing member.profile.details.department and member.profile.avatarUrl.
	•	Event Listeners: Attaching click handlers dynamically to generated elements in a loop.
	•	State & UI Toggling: Mutating data (!isAvailable) and synchronizing DOM attributes/classes on user click.

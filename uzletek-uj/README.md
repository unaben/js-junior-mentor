# Városi üzletkereső

Static site (HTML, CSS, vanilla JS, XHR). Serve it at `http://localhost/uzletek`
(copy this folder into your web root, e.g. `htdocs/uzletek`).

API base is set at the top of `js/app.js` (`API_BASE`), default
`http://localhost:3002/web/api/uzletek/uzlet`.

`img/` and `favicon.ico` contain PLACEHOLDERS – overwrite them with the files from `forrasok`
(same file names). Replace "Vezetéknév Keresztnév" in the footer with your name.

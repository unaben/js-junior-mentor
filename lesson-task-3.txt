Task: Build a Feature Showcase Component (Responsive Layout)
Could you build the feature showcase section shown in the image using HTML, CSS, and Flexbox/Grid? 
Focus on clean semantic tags, layout positioning, and responsive design.
You can grab placeholder images from Unsplash and icons from Flaticon (or use SVGs).
Requirements & Layout Guidelines
1. Top Section (Hero Header)
	•	Heading: Main title using <h1>: "Five layers. One platform. Open at every layer."
	•	Subtext: A centered paragraph <p> below the title detailing the layers.
2. Main Feature Area (Desktop Layout)
Structure this section into a 3-column layout:
	•	Left Column (Navigation Items):
	◦	Vertical list with icons on the left and text on the right (Managed Agents, Data & Learning, Inference Engine, Core Cloud, Infrastructure).
	◦	Give Managed Agents an active state with a rounded cyan pill background.
	•	Middle Column (Visual Display):
	◦	Display a centered card image with rounded corners (border-radius: 12px).
	•	Right Column (Feature Details):
	◦	Title (<h2> or <h3>): Managed Agents
	◦	Description paragraph explaining the feature.
	◦	A horizontal divider line (<hr> or border).
	◦	Products: An unordered list (<ul>) listing items (Open Harness, Sandbox, Plano, Toolbox, State).
	◦	Open Source Integrations: Text listing integrations (OpenCode, LangGraph, CrewAI, MCP / A2A, E2B, Daytona).
3. Call to Action (CTA)
	•	Centered pill button at the bottom: Browse all products →
Responsive Mobile Layout (@media max-width: 768px)
On smaller screens, reorder the 3-column feature section into a single vertical column in this order:
	1	Top: Text items with icons.
	2	Middle: Feature image.
	3	Bottom: Feature detail text (Title, Description, Products list, and Integrations).
Tip: Use Flexbox (flex-direction: column) or CSS Grid layout ordering to handle the mobile stacking smoothly.
Key Concepts to Practice:
	•	Semantic HTML: Use <header>, <main>, <section>, <nav>, <ul>, and <li>.
	•	Flexbox/Grid Reordering: Managing columns on desktop and stacking them cleanly on mobile breakpoints.
	•	Styling States: Styling active menu items using class names like .active.
	•	Dark UI Theme: Dark background (#030712 or dark navy), light text, and cyan accents.

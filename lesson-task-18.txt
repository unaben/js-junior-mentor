Task: Dynamic E-Commerce Product Catalog with Status Filtering
Description
In this task, you will build an interactive product catalog. You will dynamically render a list of products from an array of objects, filter the list in real time based on user text input, apply conditional styling for out-of-stock items, and allow users to toggle stock availability using a click event listener.

Step-by-Step Instructions
	1	Target Key Elements:
	◦	Select #product-list and #category-search using document.querySelector.

	2	Build renderCatalog(productList) Function:
	◦	Clear the #product-list container (innerHTML = '').
	◦	Conditional Check: If productList is empty, render a simple <li> with class no-results stating "No products found matching that category." and return early.

	◦	Loop over productList using a for loop.
	3	Construct Item Elements inside the Loop:
	◦	Create an <li> element (document.createElement('li')) and set its base class to product-card.
	◦	Conditional Styling: If product.inStock is false, add the out-of-stock class to the li element (li.classList.add('out-of-stock')).
	◦	Create <img> using DOM methods:
	▪	document.createElement('img')
	▪	Set src to product.details.image
	▪	Set alt to product.details.name
	▪	Add class product-img
	◦	Create Info <div>:
	▪	Create a div element with class product-info.
	▪	Conditionals for Badge: Determine if the item is in stock:
	▪	If true: badge HTML is <span class="badge badge-in">In Stock</span>
	▪	If false: badge HTML is <span class="badge badge-out">Out of Stock</span>
	▪	Set innerHTML to display product name, badge, price formatted to two decimals ($${product.price.toFixed(2)}), and category (Category: ${product.details.category}).
	◦	Create Action <button>:
	▪	Create a button element with class stock-btn.
	▪	Text content: If product.inStock is true, label it "Mark Out of Stock". Otherwise, label it "Mark In Stock".


	4	Attach Click Event Listener to Button:
	◦	Add a click event listener to the button.
	◦	Inside the listener:
	▪	Toggle product.inStock = !product.inStock.
	▪	Re-run your render logic (or call handleFilter()) so the UI updates to reflect the new state and conditional styling automatically!


	5	Attach input Event Listener to Filter Input:
	◦	Add an input event listener to #category-search.
	◦	Extract user text using e.target.value.toLowerCase().trim().
	◦	Use .filter() (or a for loop) to return only products whose product.details.category.toLowerCase() includes the search term.
	◦	Call renderCatalog() with the filtered results.
